# Changelog

## 1.1.0 — 2026-11-20

- 配图完整保留，照片、截图、流程/接线/标注图内部文字不再强制逐字转写，也不全量移入替代文本；正文、标题、源图注、独立表格、公式和技术条件继续准确转写或阻塞复核，包括位图中的独立原文。
- 由宿主实际看图生成可靠的图片理解，通过可选 `image_understanding` 字段单独保存；程序生成“图片理解”标准引用块，保证前后空行含文件末尾，并检查实际 CommonMark 边界。整体无法可靠理解时只保留原图，不生成空块或占位、不单独阻塞。
- 页记录与清洗前后输出关联区分源文和图片理解；保留原图注、图片、来源及规则快照。既有 CLI 和任务升级后重做全部目标页的协议继续适用。
- Windows 原生 Codex CLI 0.170.0 已从开发 Worktree 实际完成真实手册第 6/7 页、清洗对照及边界反例验收；独立 workspace-write 会话完成原生 Skill 加载和合成 PDF 转换，40 项程序测试通过。macOS、WSL、Codex GUI、Claude Code、WorkBuddy 和下游检索未实测。
