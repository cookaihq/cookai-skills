# 完整视觉单元保留

规则 ID：`visual-unit`。行为版本随 SKILL.md 的 metadata.version。以下样本是规则依据；不是每次转换的固定分支，也不是对任意文档的质量保证。

1. **适用与依据：** 主体、文字、箭头、连线、按钮或接口依靠位置表达关系。
2. **保留关系：** 视觉主体和全部相关标注、指示线、标签，确保裁图可读。
3. **处理：** 将视觉单元完整保存为图片，并按文字的作用选择表达：
   - **简短图内文字：** 内部标题、轴标及单位、图例或少量标签默认写入单行图片替代文本 `alt`，注明原图可观察的角色，如 `MXO 4 - Test signal; 横轴: Time (ms)`。可辨原文完整保留；这些标签不再各自成为图下段落，也不在 `alt` 和图下同时复制。替代文本保存在 Markdown 图片语法中，可用于检索及无图阅读；渲染页面通常不另显示它，不能假定下游索引器一定保留它。
   - **文字密集图：** 标注含多项说明、须逐项阅读，或替代文本不足以清楚表达对象对应时，在图下按对象/位置组织一组列表或“对象—原文标注”表，保留可辨文字和必要关系；`alt` 只简短标识该图。不要把完整内容概括为几个关键词，也不要将标注拆成与图片脱离的正文小节。
   - **已有文字与无文字图：** `alt` 和图下转写只补充邻近正文/标题中尚未表达的图内文字。例如邻近标题已转写 `Sweep [1]`，`alt` 只补充图内轴标及单位，省去 `Sweep [1]`；原图及原有标题照常保留，图与标题的归属由阅读顺序保持。没有可转写文字且无独立图注/说明时，`markdown` 可为空字符串，仅输出图片；`alt` 简短说明实际可见对象，不补造技术结论。
4. **反例：** 原始图注（如 `Figure 1. Test signal; vertical range 1 V/div.`）是源文独立说明，仍在图下转写，不并入 `alt` 后删掉。图旁能独立阅读的正文、表格也不因靠近图片而并入或删除。只截仪器本体会丢失连线与标注；完整保留图片也不能替代检索所需文字。源文自身重复不属于本规则的删除范围。
5. **配合：** 先用 `reading-order` 区分图内文字、源图注、独立标题/正文/表格，确定小节与归属，再定完整裁图边界及文字表达。独立表格继续由相应规则转写。本规则不触发清洗；图内文字转写不替代原图。FPL1000 两页分别保存，不自动拼接。
6. **不确定处理：** 检查边界外可能被截断的标注，必要时重新渲染放大；看不清的文字或无法确定的对应关系保留源图并标疑点，不猜写文字或补造关联。
7. **样本与预期：** Issue 12 合成信号图的 `MXO 4 - Test signal` 与 `Time (ms)` 进入 `alt`，原图注仍在图下，电气表和测试条件独立保留。FPL1000 第 8、9 页完整示意图及 ZNH 第 8/10 页密集标注按对象归组；FPL1000 第 8 页已有的 `10.1"高分辨率显示器` 标题不再复制，但 `1280像素×800像素分辨率` 等独有信息仍保留。ZNH 独立电压表正文、RTC 右侧表格为分区反例。无文字图不新增正文；方括号编号等字面字符照常保留。
8. **检查：** 工具检查真实图片、相对引用、替代文本字面字符及输出行映射；Agent 对照源页检查主体/连线/标注完整清晰、可辨文字可检索且角色或对象对应正确，简短标签没有散落为独立段落，密集图文归为一组。核对原始图注、正文、技术数值和表格未遗漏；邻近已有转写不复制，无文字图不强填正文，疑点已保留。
