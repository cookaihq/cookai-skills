# 完整视觉单元保留

规则 ID：`visual-unit`。行为版本随 SKILL.md 的 metadata.version。以下样本是规则依据；不是每次转换的固定分支，也不是对任意文档的质量保证。

1. **适用与依据：** 主体、文字、箭头、连线、按钮或接口依靠位置表达关系。
2. **保留关系：** 视觉主体和全部相关标注、指示线、标签，确保裁图可读。
3. **处理：** 将具有这些关联的区域作为完整图片保存并正确引用，同时默认在图下补充可辨认的标签、编号和说明，按原图对应关系组织文字。与邻近正文（包括已有标题）相同的图内文字不再生成额外文字副本，保持与已有转写的关联。即使源页在标题和图中各出现一次，也应保留原图及原有标题，只省去图下新增的相同转写；这一约定不删除原图内容，也不构成自动清洗原文重复正文的依据。相邻的独立正文或表格另外转写。FPL1000 两页各自保存，不自动拼成跨页大图。
4. **反例：** 图旁存在文字不表示整块都应截图；可以独立阅读的正文不因靠近图而自动并入。只截图仪器本体会丢失关联。
5. **配合：** 先用图文关联规则定小节和区域，再定完整裁图边界。图内补充文字转写不得替代原图。
6. **不确定处理：** 检查边界外可能被截断的标注，必要时重新渲染放大；看不清的文字或无法确定的对应关系保留源图并标疑点，不猜写文字或补造关联。
7. **样本与预期：** FPL1000 第 8、9 页完整示意图；第 8 页的 `10.1"高分辨率显示器` 已作为邻近标题转写时，图下不另生成相同标签文字，源图内容完整保留。ZNH 第 8 页塔架图、第 10 页仪器标注图；RTC 面板图。ZNH 独立电压表正文和 RTC 右侧表格提供分区边界。
8. **检查：** 工具核对文件和引用；Agent 核对主体、文字、连线完整及清晰度，逐项核对图下转写的标签、编号和说明与源图一致且能检索；邻近正文已有相同文字时不重复转写，省去副本后仍保留归属关系，无法辨认的部分已标明疑点。
