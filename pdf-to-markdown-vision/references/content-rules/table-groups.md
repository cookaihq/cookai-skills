# 表格语义分组与拆分

规则 ID：`table-groups`。行为版本随 SKILL.md 的 metadata.version。以下样本是规则依据；不是每次转换的固定分支，也不是对任意文档的质量保证。

1. **适用与依据：** 整行是后续行的类别标题，或同一表内存在可独立解释的测量项目、表头和条件组合。
2. **保留关系：** 每组名称、列含义、数据行、共同条件、单位和脚注；不得扩大条件覆盖。
3. **处理：** 类别行可转换为小标题，后接独立简单表格；必要时重复表头。ZNL 幅度噪声与相位噪声可拆成两表，各自保留共同条件和实际频段。
4. **反例：** 整行共享测试条件、注释或汇总行不因占满一行就成为分类标题。外观复杂不自动意味着需要拆表，拆后有歧义则保留关联或标疑点。
5. **配合：** 合并与共同条件规则决定条件覆盖；公式规则处理表内表达；页内图表顺序沿图文关联规则。
6. **不确定处理：** 查看分组前后行和必要的续页，无法判断标题/条件时保留区域与疑点，不仅靠粗体或跨列样式分类。
7. **样本与预期：** MXO5 用户所说第 25 页截图实际位于物理/印刷第 24 页，第 25 页为同表续页；探头类别作为组标题，各表保留 Designation、Type、Order No.。ZNL 第 11 页 Trace noise magnitude/phase 分组后各自保留 source power 0 dBm、0 dB reflection、bandwidth 10 kHz、specification/typical 和脚注 5。
8. **检查：** 行、列、值无丢失；分类与条件有区分；ZNL 两组频段不同，不能人为对齐或补齐。该样本的条件行可作反例；这不等于已承诺通用跨页表格拼接。
