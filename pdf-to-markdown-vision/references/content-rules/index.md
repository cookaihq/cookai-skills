# 内容规则索引

先看页面，再读取符合可观察关系的规则。输出中用稳定 ID 关联当轮快照。普通正文也按 reading-order 保持章节和段落顺序。独立原文的数值、型号、单位、脚注、安全提示与重复内容均保留；删除需要独立清洗要求。

| ID | 主题与读取条件 |
| --- | --- |
| `reading-order` | [阅读顺序与图文关联](reading-order.md)：多栏、图文归属、相邻列表的同组延续或独立分隔 |
| `visual-unit` | [完整视觉单元与图片理解](visual-unit.md)：保存配图时必读，图内文字、图片理解与必须转写的独立原文边界 |
| `table-groups` | [表格语义分组与拆分](table-groups.md) |
| `merged-conditions` | [合并单元格与共同条件的适用范围](merged-conditions.md) |
| `formulas` | [表格内公式忠实转写](formulas.md) |

规则正文按八项结构维护。独立原文的准确性疑点继续阻塞；配图内小字或整体含义不明按 `visual-unit` 省略不可靠解释，不因此阻塞。不由文档厂商或页码触发专用分支。各规则样本中的物理页与印刷页分别标明；截图不证明完整 PDF 页序。
