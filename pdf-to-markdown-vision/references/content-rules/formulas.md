# 表格内公式忠实转写

规则 ID：`formulas`。行为版本随 SKILL.md 的 metadata.version。以下样本是规则依据；不是每次转换的固定分支，也不是对任意文档的质量保证。

1. **适用与依据：** 单元格含分式、上下标、关系符号或条件化数学表达，能从源页辨认结构和单位。
2. **保留关系：** 比较符号、分子分母作用域、下标、加法项、单位、nom. 等限定，及频率和耦合条件的对应。
3. **处理：** 默认使用 LaTeX 数学格式，保留分式、上下标等结构。明确用于不支持数学渲染的系统时，改用括号清楚的等义纯文本表达。接收系统未指定时沿用默认，不要求每次询问渲染能力；不能以排版形式改变原式含义。
4. **反例：** 不把分式展平成歧义文本，不把 mV_pp 当成普通变量乘积，不交换各频段公式或把 DC/AC/LF/noise-reject 条件并入独立 HF-reject 组。
5. **配合：** 表格分组与共同条件规则先确定公式适用行；图像保留规则用于不清晰区域兜底。
6. **不确定处理：** 局部放大并用文字层辅助核对；仍不能可靠识别时保存公式源图及疑点，不用猜测的公式标为完成。
7. **样本与预期：** RTA4000 第 7 页，包括大于 2.2 mV_pp 除以 input sensitivity 再加 1 div 的表达，以及其他行 1.5/+0.8、0.6/+0.4 的对应参数。每行具体条件和符号以该源页为准，不从示例数值推导其他行。
8. **检查：** 逐项对照关系符号、分式范围、下标、数值、单位和条件。清晰源页已观察；模糊公式及不同 Markdown 展示环境的边界验收待准备，当前不承诺通用数学公式识别。
