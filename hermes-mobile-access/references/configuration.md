# 配置与稳定连接

## 配置页面快捷入口

沿用 `SKILL.md` 的锁定命令入口和真实项目、个人配置启用、保存范围及已明确的连接/FRP 上下文。已有准确连接 ID 时直接传 `--connection`；否则只运行 `connections list` 取得实际集合与默认项。无连接也能打开配置页；唯一连接或有效默认按原选择协议处理，多个连接且无法唯一确定目标、默认失效时先让用户选择，不猜第一条。

然后直接 `configure start`。它已内建探活、同归属复用及失效重启；结果未确定才以相同上下文 `configure status` 核查。无需提前 `discover`、`profiles`、`doctor`、`plan` 或 `probe-domain`。页面所需真实身份、配置来源和后端所有者校验继续保留；校验失败如实显示，不造候选。只交付有效链接与实际剩余空闲期限，不连接 FRP、不调用聊天，也不因保存自动接入。

业务键按进程环境 → 调用项目 `.env.hermes-mobile-access` → `.env.local` → `.env` → 显式启用的个人 `~/.config/hermes-mobile-access/.env` 读取。不搜索父目录、其他 Skill 或备份；FRP 的凭证始终由 FRP Launch 自己加载。

`HMA_CONNECTION` 保存默认稳定 ID，`HMA_CONNECTIONS_JSON` 保存 `{"schema_version":1,"connections":{...}}`。ID 为程序生成的 `hma_<32位小写十六进制>`；连接显示名称按 Unicode NFC、去首尾空白与 casefold 比较唯一，1–64 字符，可含中文和空格。

配置集整套选择来源，高层不逐字段/连接补齐低层。空字符串回退，合法空集合遮蔽低层。JSON 损坏、重复键/名称、未知 schema、非法字段或类型返回实际来源错误；默认不存在或失效则明确选连接，不自动取第一条。环境来源只读，不能另写低层文件假装修复。

记录包含 `name`、`domain_prefix`（默认 `hermes-mobile`）、`hermes`（`home/preferred_profile/profile_home`）、`frp`（原 `project/home/source_binding`）、`auth`、`auto_recover`（默认 true）和 `access`（默认空对象）。未知字段拒绝。`auth` 接受未配置的 `null`，或严格对象 `{"type":"mobile_key_v1","key":"<43 字符规范 Base64URL>"}`；密钥由 32 字节安全随机数生成，未知类型/字段、不合法编码及掩码均拒绝。逻辑路径须经真实后端核验；不能把目录字符串当身份凭证。

`access` 包含可省略的 `websocket_enabled`、`http`、`websocket`。总开关和每个分组均为严格布尔值，省略为 true；字符串 `"false"`、数字、null 和未知分组拒绝。分组键为 `sessions`、`cron`、`profiles`、`models`、`skills_plugins`、`tools_mcp`、`files_audio`、`messaging`、`memory`、`configuration`、`maintenance`、`other`。例如 `{"http":{"cron":false},"websocket":{"cron":false}}` 关闭定时任务的两种直接接口，其他项保持默认开启。

配置页显示各开关的真实 JSON 路径及文件来源。恢复默认移除显式值；总开关关闭不擦除分组选择，无自动保存。策略加入运行绑定摘要，语义相同的缺省/显式 true 不触发无谓重连。运行中保存权限变化使用与域名变更相同的预检、停旧启新和条件恢复流程，旧 WebSocket 不继续使用旧策略。外部修改由运行期绑定检查撤销，不承诺瞬时生效。升级 0.1.x 后首次应用 0.2.0 需通过管理入口断开并重连当前接入进程，保留原项目、来源、密钥、域名和后端。

配置页生成新密钥只更新草稿，保存才写入；眼睛与复制原值均需显式动作和当前修订，普通响应/回执不含原值。清除不会回退到其他连接或来源中的密钥。替换/清除使使用旧绑定的接入层在检查时关闭现有流并拒绝新请求；检查间隔与检查预算分开，不承诺瞬时撤销。普通改名不改变运行绑定。实际永久保存/清除沿用当前用户授权；选择认证方案本身不代表已创建生产密钥。

配置页从 `profiles` 的真实核验结果提供平铺选项，短缓存仅用于页面读取；保存前重新核对实例和列表修订，并一起写入逻辑 home、首选名称及解析目录。身份变化、已有连接绑定另一 home、目标未由当前后端提供时拒绝修改。此操作不调用 Hermes 的切换 profile 接口；已保存首选值不表示手机正在使用它。

父域只取 FRP `context-info`：明确后缀优先，未另设时取生效完整连接中的域名主机；接口会报告来源及依据。HMA 不保存平行父域或 FRPS 凭证，不把可选后缀缺失当成需要用户重新配置，也不把控制连接端口拼入 HTTPS Server URL。上游来源改变使旧检查失效；生成的地址不等于已生效入口。

同文件锁、修订复核、私有临时文件与原子替换保护保存，保留无关 dotenv 行。锁只协调遵守此协议的本机写入者，不能排除外部编辑器的极小检查后竞态。项目保存须未跟踪且已忽略；新建只写 `.env.local`，已有来源就地修复。改名保留 ID/default，不重启。删除默认记录同时清除该文件的选择器，并保留合法空集合。

`AUTO_UPDATE_CHECK` 独立于业务层级，只读个人文件；0 关闭，其他值默认开启。页面单独保存该开关无需创建连接。业务配置来自项目文件时，与个人更新开关的修改分两次保存，避免伪装成跨文件原子事务。

运行身份固定本次 ID、权威来源和已核验实例，不追随后来切换的全局默认项。FRP 进程文件由 FRP Launch 管理，HMA 连接记录在 `<home>/runtime/connections/<ID>/`，UI 生命周期记录在 `<home>/runtime/ui/`；两种日志均为 1 MiB × 3，不含凭证。控制器退出后 FRP 所有者监控停止专属实例；配置页退出不停止业务连接。
