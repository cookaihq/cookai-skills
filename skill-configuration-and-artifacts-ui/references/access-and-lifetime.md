# 生命周期与访问

本文件适用于实际提供的页面。页面及服务数量来自已确认的业务方案；统一工作台、已有界面和完全定制实现不因同时涉及配置与产物而拆成两个服务。

## 访问与数据边界

本地页面固定目标与项目，默认空闲 60 分钟到期。用户实际点击、输入、滚动等操作续期；轮询、被动刷新请求不续期。按实际页面/访问会话核对续期范围，结束或到期不终止业务任务、不删除配置与已存结果。

配置访问不提供常驻。定制统一界面同时包含配置和产物时，可使用统一的限时会话；若业务需要产物常驻，须隔离配置访问期限，不能用隐藏配置控件代替服务端到期。是否使用多个进程由实现方案决定。

启动、状态、停止须验证服务归属（目标、项目、页面、实例），避免误停其他任务。端口随机选用，默认仅监听 loopback。启动链接的授权放在 URL fragment，交换后清除 fragment；session cookie、CSRF、Host/Origin、访问到期在服务端验证。所有敏感响应 no-store，运行目录仅本机用户访问，日志轮转并避免凭证及完整授权链接。停止以实例接口执行，不按进程名批量杀进程。

## 共用模板的生命周期

仅选用 `skill_ui` 核心时适用：配置模板与产物模板各自对应独立页面和本地服务，只启动所选页面；两者都选用时，授权、计时和停止互不影响。只选一个模板不启动另一个服务。

产物模板显示倒计时和“常驻”复选框；旁边提示“常驻会持续占用系统资源”。选中只对本次服务有效，刷新/关标签不改变；手动停止或电脑重启结束，下次默认倒计时。取消常驻重新开始 60 分钟。配置服务不提供常驻，产物常驻不得延长配置访问。定制实现按其已确认的交互呈现期限和资源影响。

## 配置页面快捷入口

为有业务配置页面的目标，在 `SKILL.md` 尽早识别显式调用后的内容：去掉首尾空白后恰为 `配置`、`配置页面`、`打开配置`、`打开配置页面`、`设置`、`设置页面`、`打开设置`、`打开设置页面` 中任一项，直接打开该目标已有配置页面或统一工作台的设置区域。参数、预设、字面 `--` 或附带业务正文继续原流程；不要从任意正文中搜索“配置/设置”截走任务。

快捷分支先于更新联网检查、默认设置提醒、业务素材/依赖准备、模型查询与在线鉴权，不要求业务凭证齐全。只运行页面自身必要的锁定环境与安全检查，保留真实项目/Worktree、caller、宿主、身份/连接、全局开关和已选范围。存在实际连接歧义时只澄清目标，不猜测。

复用目标原有 `start/status`。若 `start` 已核对归属、探活并复用/重启，直接调用一次；结果未确定时才用 `status` 核查，明确失效才重新启动，不增加重复的探活循环。Plugin 继续使用本 Plugin 统一配置中心；已有工作台可用其受支持的导航参数定位设置，不增加 launcher、注册表或常驻服务。

成功后按下方交付规则给出有效链接与实际剩余空闲期限并结束本次请求。复用实例不能把余期重算为完整 60 分钟；旧链接、旧进程记录或静态文件不是可用性证据。页面保存不授权新业务；仅在原任务和原授权仍有效时接续。

## 重开入口

交付前从目标项目已有说明或入口核对页面的启动、状态与停止方式。新会话应能凭项目位置、目标 Skill 名称和实际页面名称找到它；缺少定位信息时，在目标项目既有说明中补齐入口、必要参数及数据归属。复用已有记录，无需为此建立全局注册表，不记录完整授权链接或密钥。

重开时先定位指定项目（含实际 Worktree），检查现有服务归属及可用状态。确认属于同一目标、页面和实例后，按实际入口取得有效访问链接；已到期或停止则重新启动并核验新链接。目标不匹配时不复用或停止其他服务。项目、启动入口或所需数据已不可用时说明具体缺项，不承诺恢复已删除的临时预览或依赖旧会话记忆。

## 交付链接

首次交付该页面时，提供链接、真实期限、一条可跨会话使用的重开请求和简短手机提示。默认期限写“空闲 60 分钟到期。”；非默认期限或本次常驻如实说明。

重开请求采用：“请打开项目【项目绝对路径】中【业务 Skill 名称】的【页面名称】，给我新的访问链接。”实际交付填入准确项目或 Worktree、目标业务 Skill 与页面名称，不留占位符。这一条同时适用于当前会话、当前项目新会话和其他项目新会话，不默认罗列三套长提示。多页面按实际归属处理。

手机提示只写：“手机访问：告诉 Agent‘我要用手机打开这个页面。’”不要求普通用户先选择网络工具。尚未请求跨设备时，不例行调查或解释 FRP/Tailscale 的安装状态和网络细节。

同一会话再次交付同一页面，只给有效链接和真实期限；用户询问或归属变化时再补充重开信息。重新打开配置页仍按当前意图决定默认字段，不沿用过时目的。

用户真正要求开放时，再使用已有 FRP/Tailscale 工具。绑定实际外部 origin，验证 Host/Origin、授权交换、cookie、CSRF、文件与生命周期。配置含可查看原值的密钥，跨设备入口须有 HTTPS 加密或已验证的加密私网通道；网络能连通不等于 UI 授权可用。默认不自动开隧道，不把 loopback 地址当手机地址。
