# 产物展示

产物是对用户有意义的业务成果，包括本地文件、结构化结果、远端资源和操作回执。任务状态和错误可作为上下文；缓存、恢复指针、调试日志不自动算产物。仅根据目标已记录的归属展示当前项目，其他项目另开入口。文件可以存放在项目外，但须有明确归属记录，不扫描其他项目拼接结果。

按业务流程选择展示位置和布局：可以位于统一工作台、已有界面或独立页面，也可以完全定制。涉及产物不等于必须采用集合模板。

选用本 Skill 的产物模板时，默认采用“产物集合”：搜索、类型/任务过滤、卡片/列表；选中后进入大面积专注预览。桌面可折叠集合侧栏、按需展开元数据；手机采用集合→详情→返回，保留筛选、布局和位置。单项结果可直接进入详情。表格、文档对照、远端回执等是按业务选择的详情视图。

采用共用核心时，由业务适配器将现有记录映射为最小的可定位条目，复杂数据和定制视图独立维护；其他实现使用目标自身的数据接入方式。所有实现均保留业务字段、存储与历史模型的实际含义，不强制新增统一日志表。

默认操作为查看、过滤、预览、打开、复制与下载，按内容是否支持呈现。编辑、AI 改写、分享、执行、重试/取消/删除、版本管理或重生成链接需按目标确认，不能因为参考 ChatGPT/Claude 产物交互就自动加入。

按真实情况显示缺失文件、部分完成、过期链接、空集合和读取失败；失败时清除旧内容，重试成功才恢复。没有历史记录时说明覆盖范围，不声称已有全量历史。大文件采用流式下载及 Range，分页、刷新和历史保留按目标规模设计；高成本预览按需加载。动态 HTML/不可信文档保持隔离或提供下载，不能与配置页同源执行任意脚本。
