# 验收

先读取目标已确认的实际验收 Agent 名单、支持平台与安装形态；缺项询问用户。兼容目标和必需实测名单分别记录。本 Skill 不规定所有目标必须使用某一个 Agent。

使用合成数据及独立项目，按本次选定的能力、页面和实现检查受影响行为；未选的模板及不存在的页面标为不适用，不为凑齐验收新增功能。

## 决策与交付

- 调查结论分别覆盖 UI 必要性、页面组织、模板适用性，能对应实际业务和源码；展示方案只含涉及的能力。已确认的决定不会在后续预览、接入或验收时被强制双页面或共用核心覆盖。
- 无需 UI 时交付评估结论，无页面、服务、展示表或 vendor 副作用；仅评估任务不执行改造。
- 首次交付页面的有效链接、真实期限、一条填好的通用重开请求和简短手机提示，遵守 [链接交付](access-and-lifetime.md#交付链接)。同会话重发同页面只给链接与期限；请求填好实际页面、业务 Skill 和项目/Worktree 路径，不留占位符。
- 从目标项目说明或入口可以定位启动、状态和停止方式。当前会话、当前项目新会话及其他项目新会话都按请求定位同一目标；核验已有服务后取得有效链接，到期/停止后可重启。服务归属不符或输入已不存在时准确报告，不能误复用其他项目或声称恢复成功。

## 按能力与实现验收

- 配置方案、新建接入和存量改造均不引入或保留 Secret Book 方式，包括独立入口、备用分支、缺项/修复引导和文档。改造前已保存的合成本机配置仍可供原业务读取，配置优先级和范围不变；用户数据未被迁移或删除。仅评估任务应列出必要调整而不实施。
- 涉及配置管理：缺业务配置仍可启动相应界面；敏感值脱敏、按需查看、替换、清除、刷新复位；验证、冲突和保存范围正确。
- 一次保存，无自动写入；默认/继承/显式、只读、依赖、顺序列表和共享影响与原加载器相同。回执不含原值；原任务续接关联明确。
- 在未预置忽略规则的新 Git 项目完成首次保存，核对配置、实际临时文件、锁和需要的私有恢复目录已忽略；重复保存不增长规则。覆盖嵌套否定、路径特殊字符、已跟踪目标拒绝且索引不变、权限失败保留草稿与修复重试，以及原有冲突和回滚。读取和预览不修改配置、忽略规则或回执。
- 字段的来源详情显示适配器给出的真实 Key/JSON 路径；使用内部 ID 与真实 Key 不同的样例验证映射。编辑刷新后标识仍正确，长名称在窄屏折行，公开响应和未主动显隐的页面不包含密钥原值。
- 多层配置：全局完整、项目仅覆盖 API Key 时，其余项逐项继承；同一作用域多个文件的优先级与真实加载器相同。移除/空值回退、零值、全部缺失、字段默认、全局启用开关、只读环境覆盖、不可读文件、整组绑定不跨层拼接分别核验。预览不写文件，低层保存成功不误报生效；普通响应、每层明细、预览和回执均无密钥原值。
- 支持 Plugin 项目后缀时，验证 local/普通两层的顺序、共享影响、无调用方入口、独立保存与回退；新增 Secret 的本地目标与普通文件修复限制分别测试。退出来源时用有值及不可读的合成文件验证不参与，检查保留的 Skill 子目录和普通 Skill 回退仍生效。通用核心不硬编码某个目标的层数或退出政策。
- 选用配置模板：同一 Skill 按本次入口目的展示不同字段，始终补入当前必要缺项，依赖新激活的缺项及时展示。默认值、继承值、`0` 与 `false` 不误报缺失；已展示的必要项在填写保存后不消失。其他设置在同一表单展开，没有模式切换或抽屉。
- 验证顶部双范围直接可见、普通用户可理解的逐项覆盖说明、单范围不出现选择器、修改已有项目值沿用原目标。文件细节默认折叠；展开先显示相关文件、进一步展开才显示完整规则；默认文件不是从优先级首尾推导。有值高亮，“本次保存位置”不误标为整个文件生效。逐字段目标限制、禁用来源与只读来源如实呈现。
- 切换范围/文件或折叠字段保留各自草稿；一次仅保存选中文件的修改，其他草稿保留。缺 API Key 时修改其他有效字段可保存，仍提示业务尚未就绪；非法类型、关联完整性、必要值破坏、整组记录等错误继续拒绝且文件不变。外部冲突保留输入，重载后重新预览。
- 桌面及窄屏表单的最后控件、保存按钮和按钮下方反馈可达；普通输入焦点和选区在预览后保留，键盘可切换范围与展开其他设置。保存后留在页面，提示用户回到 Agent 对话窗口发送“配置已保存，请继续。”单文件目标也完成闭环。定制实现验证已确认的交互，不强制相同布局。
- 涉及产物展示：验证所选布局与真实预览/打开/下载等已提供操作，空结果、读取失败、缺文件、过期及部分结果如实呈现；选用产物模板时再验集合与详情、筛选/返回及手机布局。
- 实际页面/访问会话：后台轮询不续期、实际操作续期、停止/到期不影响业务任务和记录。统一界面核对其实际授权和期限边界，配置访问不被产物常驻延长。采用核心的两个模板时才验两服务独立；只选一个模板不应启动另一服务。选用产物模板时再验常驻提示、刷新保留、取消重置及重启默认倒计时。
- 未授权、错误 Host/Origin/CSRF、路径越界、非白名单文件拒绝；实际启用跨设备时验证完整代理入口。
- 二次接入不重复创建或覆盖业务定制与用户数据；发布副本可独立运行。采用核心时核对固定版本、校验清单及冲突保护；未采用核心的目标无 vendor 依赖。

## 本开发 Skill 的行为验收

在用户选定的实际 Agent 中发现并触发被测版本。规则变更覆盖受影响分支：无需 UI；按打开目的选字段、必要缺项、单/双范围与展开其他配置；同时涉及配置与结果、适合一套定制界面的业务；只选择一个模板；确需多个页面。测试提供真实请求和最小原始材料，不提供预期结论；检查 Agent 的实际方案、读取路径和操作。重开验证另用没有旧会话上下文的会话，从目标说明定位入口并取得可用链接，检查简化交付提示及项目绑定。CLI/脚本结果不替代宿主行为验收，纯规则变化不重跑无关模板交互。

验收记录包含代码版本、系统、宿主版本、入口、输入、预期、结果与未执行项。核心测试可通过 `uv run --frozen --project <本Skill> python -m unittest discover -s <本Skill>/tests -v` 运行；这些测试仅验证共用代码。业务目标必须另验自己的加载器、存储和原功能。合成示例不能证明真实业务接入成功。
