# 配置中心

同一配置中心提供“必要配置”和“全部配置”两种视图，使用相同字段定义、校验和保存逻辑。必要配置显示当前依赖条件生效的全部必填字段，已填值继续显示并可修改；只读与敏感值规则照常生效。保存、重载或切换视图后仍按是否必填筛选，不按是否缺值隐藏。业务因缺项受阻时进入前者，说明用途，可切到全部配置；主动查看/修改时进入后者。UI 启动独立于业务凭证，缺项不能阻止页面启动。

页面绑定明确 Skill/Plugin 及本次项目。不提供凭证来源区、来源选择、路径选择器或没有意义的单选服务。保存的范围、实际位置和覆盖影响仍须可见；后台按目标真实配置协议处理，页面省略“来源”不改变加载优先级。

## 配置方式与存量改造

配置中心由用户直接填写、查看和修改设置，保存到目标已确认的本机配置。Secret Book（`secret-book`）已退出本 Skill 的配置方案：新建不引入，改造不作为独立、可选、备用或兼容入口保留，也不委托它取值、保存或修复配置。这一边界覆盖方案、界面和非 UI 流程，不能仅隐藏页面入口。

改造时查清目标中的来源选择、命令分支、缺项/修复引导、调用方与使用说明，将相关入口改接配置中心；无其他用途的 Secret Book 专属代码随之移除。只评估时列出这些必要调整，不执行修改。涉及本次授权范围外的调用方时报告依赖与未完成范围，不以另留旧入口作为完成方案。

已有本机配置继续通过真实加载器读取，保留其分层优先级、保存范围及有效值；曾由 Secret Book 写入的值也是已有配置。退出该方式不授权读取、迁移或删除用户的 Secret Book 数据、凭证及其他项目配置。

## 字段与语义

- 全部配置覆盖目标正式支持的全部持久用户设置和高级项；Plugin 共享项集中展示，各 Skill 专用项分组并说明影响。宿主设置仍归宿主管理。
- 每次任务的临时参数留在原任务入口，用户明确要求才纳入 UI。默认值、继承值和显式值必须区分；顺序列表、依赖、只读和生效时机保留原含义。
- 保存目标由已确认方案/真实加载器确定。一个固定目标不渲染选择器；有真实业务多目标需求时先确认交互，不能恢复通用凭证“来源选择”。

## 敏感值与保存

已保存密钥默认中间脱敏；眼睛按钮按用户动作读取并显示原始值，再点隐藏。替换与清除是独立编辑动作，刷新重置为脱敏。掩码不是表单真实值，不能提交或写回。短密钥避免暴露全值。日志、通用状态、任务回执、异常与 Agent 回复不包含原值。

一次“保存”提交变更，保存前在页面显示范围、位置和变更摘要；编辑不自动写入，不加第二次确认。清除说明移除哪个显式值以及是否回退默认/继承值。存在高优先级覆盖时说明实际效果，不把写成功当作已生效。

保存区域固定在视口底部，默认收起为紧凑栏，显示“本次修改”、未保存项数、展开入口和保存按钮。展开后向上显示变更摘要与校验说明，保存按钮位置保持不变；展开或收起保留编辑草稿。保存成功与失败反馈在收起时仍可见。正文按区域实际高度留出空间，最后一个字段和接续提示可滚动到无遮挡位置；桌面和窄屏均保持可用。长摘要在区域内滚动，保存按钮持续可操作，保存失败时显示错误位置。

服务端复核类型、枚举、依赖、必需项和只读权限。验证失败不部分保存。写入前检测读取以来的文件/语义变化；冲突保留页面草稿，提示重新载入核对。多文件目标必须使用目标自己的事务/回滚机制；单机锁只协调参与同一协议的写入方。

## 保存后接续

保存回执仅包含任务标识、必要的输入/项目绑定、配置修订号、校验类型及结果。仍在等待的 Agent 核对任务和授权有效、配置已满足后继续原任务；本次保存并不授权新任务或结果不明请求重发。会话结束时显示可复制的继续请求。页面只管理配置，不代替 Agent 重发业务调用。连通性/鉴权校验需由适配器明确实现并标记，普通格式校验不能宣称 API 可用。
