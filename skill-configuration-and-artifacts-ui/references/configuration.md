# 配置中心

同一配置中心提供“补齐必要配置”和“全部配置”两种视图，使用相同字段定义、校验和保存逻辑。业务因缺项受阻时进入前者，说明用途，可切到全部配置；主动查看/修改时进入后者。UI 启动独立于业务凭证，缺项不能阻止页面启动。

页面绑定明确 Skill/Plugin 及本次项目。不提供凭证来源区、来源选择、Secret Book 路径、路径选择器或没有意义的单选服务。保存的范围、实际位置和覆盖影响仍须可见；后台按目标真实配置协议处理，页面省略“来源”不改变加载优先级。

## 字段与语义

- 全部配置覆盖目标正式支持的全部持久用户设置和高级项；Plugin 共享项集中展示，各 Skill 专用项分组并说明影响。宿主设置仍归宿主管理。
- 每次任务的临时参数留在原任务入口，用户明确要求才纳入 UI。默认值、继承值和显式值必须区分；顺序列表、依赖、只读和生效时机保留原含义。
- 保存目标由已确认方案/真实加载器确定。一个固定目标不渲染选择器；有真实业务多目标需求时先确认交互，不能恢复通用凭证“来源选择”。

## 敏感值与保存

已保存密钥默认中间脱敏；眼睛按钮按用户动作读取并显示原始值，再点隐藏。替换与清除是独立编辑动作，刷新重置为脱敏。掩码不是表单真实值，不能提交或写回。短密钥避免暴露全值。日志、通用状态、任务回执、异常与 Agent 回复不包含原值。

一次“保存”提交变更，保存前在页面显示范围、位置和变更摘要；编辑不自动写入，不加第二次确认。清除说明移除哪个显式值以及是否回退默认/继承值。存在高优先级覆盖时说明实际效果，不把写成功当作已生效。

服务端复核类型、枚举、依赖、必需项和只读权限。验证失败不部分保存。写入前检测读取以来的文件/语义变化；冲突保留页面草稿，提示重新载入核对。多文件目标必须使用目标自己的事务/回滚机制；单机锁只协调参与同一协议的写入方。

## 保存后接续

保存回执仅包含任务标识、必要的输入/项目绑定、配置修订号、校验类型及结果。仍在等待的 Agent 核对任务和授权有效、配置已满足后继续原任务；本次保存并不授权新任务或结果不明请求重发。会话结束时显示可复制的继续请求。页面只管理配置，不代替 Agent 重发业务调用。连通性/鉴权校验需由适配器明确实现并标记，普通格式校验不能宣称 API 可用。
