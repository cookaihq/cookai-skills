# 配置管理

涉及配置能力时读取本文件。配置中心指承担配置管理的界面，可以是统一工作台中的区域、已有界面或独立页面；采用哪种页面和模板由业务方案决定。配置方式、数据与保存语义适用于所有涉及配置的实现，模板交互见文末。

配置管理应覆盖补齐必要设置与主动查看/修改设置的实际需求。UI 启动独立于业务凭证，缺项不能阻止页面启动。已填的持久设置仍可查看和再次修改；只读与敏感值规则照常生效。

页面由本地服务提供，Agent 的启动入口绑定明确 Skill/Plugin 及本次项目，不让静态 HTML 猜测当前项目。优先展示本次目的相关的字段与当前缺失的必要配置；来源和文件细节按需展开。文件选择仅限真实加载器声明的目标，不提供任意磁盘路径浏览器或没有意义的单选服务。

## 降低理解成本的交互建议

为目标开发者提出以下原则，按业务需要决定真实字段、分组、额外内容和布局；不要求所有 Skill 拥有同样的字段、全局配置或项目配置。采用共用配置模板时，按这些原则实现一张可展开的表单，不提供“极简／完整”两套模式。

1. **按本次目的展开。** 首次配置、查看、修改指定项与修复可有不同的默认字段。同一 Skill 每次打开可以不同，不把敏感项当作唯一入口。Agent 根据上下文提供字段 ID，字段名称和分组保持稳定。
2. **必要缺项始终可见。** 由真实加载器核对当前生效的依赖、默认与继承；已有可用值不算缺失，`0` 和 `false` 不能当作未填。必要项不因高级分组或入口目的被隐藏；填写和保存后留在原位置，避免页面跳动。其他设置在同一表单中按需展开。
3. **保存范围直接但轻量。** 顶部常显“保存到　个人通用／仅本项目”，只显示实际支持的范围。单范围用说明文字。首次新增可在业务允许时优先个人通用；修改已有配置沿用原来源，明确指定的范围优先。双范围下持续说明：“本项目单独设置的内容优先；没有单独设置的，继续使用个人通用设置。”这是写入目标，不代表所有字段的生效来源。
4. **文件细节逐步展示。** 默认不列文件。展开后先列该范围有值、默认与本次选中的文件；完整规则和逐项来源继续按需展开。有值文件高亮，选中项标“本次保存位置”。不标整份文件“正在使用”：覆盖按 key 发生。默认写入文件由开发者声明，不能机械取优先级最高或最低的文件。
5. **允许日常查看和修改。** 显示可理解的字段名、当前值和必要帮助；真实 Key、完整路径、来源与清除操作放在需要时可展开的位置。适配器的逐字段写入限制仍须落实，不能把页面范围选择变成所有字段都可写。
6. **保留修改过程。** 草稿按文件隔离，切换范围或折叠内容不丢失；一次保存只提交当前文件中修改的项，保留其他草稿和未知配置。错误及外部冲突保留输入，重新载入后重新核对。
7. **保存与业务就绪分开。** 缺少不相关的必要项时，允许保存其他有效修改，并继续提醒业务尚不能执行。例如尚无 API Key，仍可保存目录。类型、格式、只读权限、关联依赖及真实原子记录的完整性仍校验；开发者可声明确实不可拆分的约束。共用示例不允许把已修改的必要项清为空且无有效回退，或启用缺少关联必需值的功能。
8. **保存后留在页面。** 在按钮下显示结果，并提示：“请回到 Agent 对话窗口，发送：配置已保存，请继续。”提供复制消息按钮，由用户发送，Agent 再核对配置和任务；不自动跳转或自动触发业务。

## 配置方式与存量改造

配置中心由用户直接填写、查看和修改设置，保存到目标已确认的本机配置。Secret Book（`secret-book`）已退出本 Skill 的配置方案：新建不引入，改造不作为独立、可选、备用或兼容入口保留，也不委托它取值、保存或修复配置。这一边界覆盖方案、界面和非 UI 流程，不能仅隐藏页面入口。

改造时查清目标中的来源选择、命令分支、缺项/修复引导、调用方与使用说明，将相关入口改接配置中心；无其他用途的 Secret Book 专属代码随之移除。只评估时列出这些必要调整，不执行修改。涉及本次授权范围外的调用方时报告依赖与未完成范围，不以另留旧入口作为完成方案。

已有本机配置继续通过真实加载器读取，保留其分层优先级、保存范围及有效值；曾由 Secret Book 写入的值也是已有配置。退出该方式不授权读取、迁移或删除用户的 Secret Book 数据、凭证及其他项目配置。

## 字段与语义

- 开发者决定哪些持久用户设置和高级项适合通过页面查看、修改；其他设置继续可由 Agent 协助配置。已纳入页面的字段可从同一表单展开；Plugin 共享项集中展示，各 Skill 专用项分组并说明影响。宿主设置仍归宿主管理。
- 在字段的来源详情中显示真实配置 Key 或 JSON 路径，长名称允许折行。由适配器声明真实字段与 UI 内部 ID 的映射，不能从按钮 ID、中文标题或密钥值猜测。编辑和刷新后仍可查看准确标识；敏感值的脱敏规则不变。
- 每次任务的临时参数留在原任务入口，用户明确要求才纳入 UI。若进程环境参与实际加载，应作为只读来源说明其覆盖效果。顺序列表、依赖、只读和生效时机保留原含义。
- 区分当前生效值及来源、各文件自己的显式值、本次编辑目标。切换编辑文件不会改变当前来源标签；保存成功也可能仍被更高层遮蔽。读取顺序不决定写回位置。
- 按真实加载器逐项解释继承，不把部分项目配置描述为整份全局配置失效。例如：**“当前项目仅覆盖 API Key，其余配置项继承全局配置。”** 若协议是逐字段首个非空值，缺项与空值继续回退，`0` 和 `false` 保持有效；全部来源缺失后才按字段定义使用默认值或报缺失。其他协议如实表达，UI 不自行变更语义。
- 同一作用域也可能有多个文件；完整明细包含它们的实际顺序、未设置/空值/被覆盖/未启用/错误状态及共享影响。全局启用条件、独立 Skill 与 Plugin 的差异从目标加载器取得，不把示例的层数或顺序固化为通用规则。参与加载的文件不可读时按原协议报告错误，不伪装成缺项或继承成功。
- 目标支持 `.env.local.<plugin-name>` / `.env.<plugin-name>` 时，将两者作为独立项目来源，按业务协议排序并说明同 Plugin 多 Skill 共用的影响。默认保存目标、可新增 Secret 的本地文件和普通文件的已有值修复分别声明，来源、预览、目标白名单与保存后回读保持一致；不因文件名相似合并层或推断权限。
- 目标已确认退出某些来源时，只移除那些准确路径的读取、来源展示和保存入口，测试其中有值或不可读也不会参与。Skill 后缀文件、Skill 子目录与普通 Skill 全局回退是不同来源，保留范围按该目标决定；某个 Plugin 的退出政策不变成通用核心规则。
- 身份、工作区、资源等绑定记录按目标协议整组读取与校验，不跨文件拼接。以一个配置项编辑完整记录，缺项明确报错。
- 保存目标由已确认方案和业务写入规则确定。单一目标不渲染选择器；多目标可在项目/全局范围内进一步选择具体文件，展示准确路径与共享影响。新增项目密钥遵守目标的私有本地文件与 Git 忽略要求，不因该文件优先级低就改写高层。

## 敏感值与保存

已保存密钥默认中间脱敏；眼睛按钮按用户动作读取并显示原始值，再点隐藏。替换与清除是独立编辑动作，刷新重置为脱敏。掩码不是表单真实值，不能提交或写回。短密钥避免暴露全值。日志、通用状态、任务回执、异常与 Agent 回复不包含原值。

一次“保存”提交所选文件的变更，保存前显示范围和修改计数，准确文件及来源按需展开；编辑不自动写入，不加第二次确认。预览通过适配器调用与正式读取一致的解析逻辑，说明移除或设为空值后实际使用哪个来源、是否仍缺失/错误，以及低层保存后是否仍被覆盖；前端不以 `default` 代替继承计算。敏感预览和每层明细也脱敏。

定制界面的保存交互按已确认方案实现；修改范围、保存动作和反馈清楚可达。草稿按目标文件隔离，切换字段、作用域、文件、筛选与关闭编辑面板均保留草稿。只保存当前文件，其他文件草稿不丢失；预览与保存失败保留输入，错误位置可见。重载后提示核对新生效结果，不自动覆盖外部修改。

服务端复核类型、枚举、依赖、关联完整性和只读权限，区分保存阻塞错误与业务必要缺项。保存校验失败不部分保存；不相关的业务缺项不阻止其他有效修改。写入前检测读取以来的文件/语义变化；冲突保留页面草稿，提示重新载入核对。多文件目标必须使用目标自己的事务/回滚机制；单机锁只协调参与同一协议的写入方。

保存已授权的配置时，自动准备必要的 Git 忽略保护：配置文件、实际临时文件、锁文件，以及业务需要的私有恢复目录。只追加对应位置的精确规则，保留用户原有内容；转义路径特殊字符，在实际目录处理嵌套否定，再以 Git 复核未跟踪且已忽略。重复保存不重复增长规则。已跟踪的配置或恢复内容仍拒绝写入，不改 Git 索引。检查失败保留草稿，说明 Git、目录权限或忽略规则的具体阻塞，修复后可重试；不自动迁移配置或改写其他来源。读取、来源展示和保存预览不准备忽略规则或写配置。Git 之外的保存仍执行原路径和权限检查，无需初始化仓库。

## 保存后接续

保存回执仅包含任务标识、必要的输入/项目绑定、配置修订号、校验类型及结果。保存后留在页面，按钮下提示用户回到 Agent 对话窗口发送“配置已保存，请继续。”收到消息后，Agent 核对原任务、项目、授权及当前配置，满足条件才继续；仍缺必要项则指出缺项。本次保存不授权新任务或结果不明请求重发。连通性/鉴权校验由目标明确标记，普通格式校验不能宣称 API 可用。

## 配置模板交互

选用本 Skill 的配置模板时，采用以下交互；完全定制或已有界面不必复制此布局。

主界面是直接编辑的表单。Agent 通过本次链接的字段选择或适配器展示信息确定焦点；页面始终补入必要缺项。其他配置按稳定分组在“其他设置”中展开，不使用模式切换、来源筛选或侧边抽屉。

顶部显示实际支持的保存范围；“保存位置与配置来源”默认折叠，展开先显示相关文件，再提供全部规则。字段的“查看来源与调整”提供真实 Key、原值显隐、移除、空值、逐层来源及撤销。预览不允许写入；保存只提交当前文件。切换范围、文件、展开与收起后保留草稿；其他文件草稿可从保存区域返回。

保存区位于表单末尾，结果显示在按钮下面，不盖住最后一个控件。必要字段在完成填写后保持位置；预览更新保留当前输入焦点和选区。桌面与窄屏验证范围选择、折叠、输入、来源、保存和接续提示可用，不给产品用户显示原型场景切换器。
