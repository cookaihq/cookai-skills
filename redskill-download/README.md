# 小红书 Skill 下载

将小红书 RedSkill 分享的技能保存到本地，保留完整官方 ZIP、解压文件、来源和校验记录。把分享文案或技能标识交给 Agent 即可；下载位置可以长期配置，也可以每次指定。

它适用于 RedSkill 商店的技能分享。普通笔记图片、视频下载另用对应工具。下载过程中会访问小红书的官方接口和 CDN，并在本地保存文件；不会安装或运行下载到的 Skill。

## 让 Agent 帮你安装

面向 Claude Code、Codex 和 WorkBuddy。将下面整段复制到你使用的 Agent：

> 请从 https://github.com/cookaihq/cookai-skills 的 redskill-download 目录安装“小红书 Skill 下载”；GitHub 网络故障时尝试同项目备用仓 https://cnb.cool/zhidateam/tannt/tannt-skills。保留已有设置，验证当前 Agent 能发现和调用它。

首次发布前，远端可能尚无此目录，需使用本地源码。本机与跨平台实际验收状态见本文末尾。

Agent 会检查 uv（Python 环境管理工具）并准备锁定环境。Claude Code、Codex 使用各自可发现的逐 Skill 入口；WorkBuddy 使用它的本地技能安装入口。安装这一个 Skill 即可，不需要安装 RedSkill 商店。

## 第一次下载

在当前 Agent 工作空间里继续对话：

> 下载小红书 RedSkill 的 qichelifestyle 技能到本地，并告诉我保存位置和是否缺件。

也可以直接粘贴“先安装 RedSkill 商店，然后安装某某技能”的分享文案；Agent 会提取目标技能标识。默认位置是当前 Agent 打开的工作空间根目录下的 `downloads/redskill`，按技能标识和版本分目录保存。需要换位置可以说：

> 这次把 qichelifestyle 下载到工作空间根目录的 tmp/_redskill。

每份结果包含原始 ZIP、解压后的 `skill/`、来源记录、文件哈希清单和缺件报告。相同版本与内容会校验后复用；新版本另存；本地改过的文件会保留，重新下载放进新副本。

**完整下载与完整可用不同。** 如果作者发布时漏传素材，下载器能保存全部已发布文件并指出缺件，不能凭空取得漏传文件。例如 qichelifestyle 2.0.0 的官方包缺少4张模特参考图片和 `assets/shot-list-template.csv`。静态检查也不能证明外部模型、凭证和运行依赖全部满足。

## 设置默认下载目录

默认位置可以直接使用，无需额外配置。要长期更改，可对 Agent 说：

> 把小红书 Skill 下载的默认保存目录设为 D:/资料/RedSkill，保存为个人全局配置，保留其他设置，并检查实际生效来源。

默认只修改个人全局文件中的 `REDSKILL_DOWNLOAD_DIR`。需要仅对当前工作空间生效时，说“只保存为项目配置”；项目设置写入运行时工作文件夹的 `.env.local`。本次临时指定位置不会更改保存配置。

| 运行环境 | 个人全局配置位置 |
|---|---|
| Windows 原生 | `C:\Users\<你的用户名>\.config\redskill-download\.env` |
| macOS / Linux | `<用户个人文件夹>/.config/redskill-download/.env` |
| WSL | WSL 内用户个人文件夹下的 `.config/redskill-download/.env`，与 Windows 原生配置分开 |

脚本按实际 Python 运行用户的个人文件夹定位，不使用 AppData，也不跨 Windows/WSL 自动读取。路径约定不代表对应环境已经实测。

实际优先级：本次指定位置 → 运行时环境变量 → 工作文件夹的 `.env.redskill-download` → `.env.local` → `.env` → 显式启用的个人全局配置 → 默认 `downloads/redskill`。空值继续回退，配置文件只读当前工作文件夹、不向父目录搜索。

Agent 的正常入口会显式开启全局配置；可说“这次不使用个人全局配置”。Agent 从打开的工作空间根目录运行，所有相对下载路径以该根目录解析，而不是以 Skill 安装位置或全局配置文件位置解析。

## 常用请求与排障

- “检查小红书 Skill 下载现在使用哪个目录和哪份配置。”——返回实际工作文件夹、目录及来源。
- “继续刚才失败的下载。”——使用相同标识和目录接续；已校验的 ZIP 可复用，不保证未完成 ZIP 的字节级续传。
- “解释这份缺件报告。”——指出缺失引用、对应文档和需作者补充的内容；下载文件保持原样。
- “把下载好的 Skill 安装给当前 Agent。”——这是下载后的另一项操作，Agent 另行检查安装位置和依赖。

接口拒绝访问、技能不存在、SHA256 不一致或 ZIP 不安全时会明确失败。限流会给出可重试时间，之后再继续，不提前重复请求。下载内容不符时保留校验记录用于定位；不要手动删掉整个下载目录重来。

## 检查更新

每次使用先自动检查本下载 Skill 的更新；检查失败仍继续下载，真正更新需你确认。可以说“关闭 redskill-download 的自动检查更新”。开关 `AUTO_UPDATE_CHECK=0` 仅在个人全局配置文件中生效，独立于下载目录配置优先级。

Git 安装使用对应系统的更新检查入口；复制安装依据随包的 `update.json` 查固定版本和提交，确认后整体更新。宿主不具备可验证的更新入口时会说明未完成，不把“重新安装最新版”冒充已固定版本。
