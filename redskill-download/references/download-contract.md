# 下载结果与恢复

脚本只读访问 `https://edith.xiaohongshu.com/api/sns/v1/creator/red_skill/get_skill_bundle?identifier=<标识>`，按响应取得官方临时 CDN URL；不依赖浏览器登录态、官方 CLI 或 GitHub 上的技能副本。2026-11-05 的 qichelifestyle 实测版本为 2.0.0。外部接口若改版，报告失败并保留已有下载，不承诺接口永久开放。

## 文件布局

```text
<下载根目录>/
  <identifier>/<version>/
    bundle.zip       原始官方 ZIP
    skill/           ZIP 的全部文件和目录，保留原始层级与文件字节
    manifest.json    来源、标识、版本、SHA256、下载时间、实际字节数
    inventory.json   每个文件的相对路径、字节数和 SHA256
    report.json      SKILL.md 入口、静态缺件和需人工判断的引用
  .redskill-state/   下载阶段、冷却截止时间、操作系统锁和未完成结果
```

不把短期签名 CDN URL 保存进日志或 manifest。来源指向可重新取得包信息的官方接口。

再次下载会先查询当前发布版本。相同内容同时校验 ZIP 和全部解压文件才复用；新增、删除或修改过解压文件均视为本地变更。版本不同分开保存；同版本内容变化或本地变更时，在目录名增加内容哈希，必要时再增加唯一后缀。不会覆盖旧目录，也不会把用户改动提交或推送。

空目录也参与复用核对。缺失的 `report.json` 可根据已验证的原始文件重新生成；已有报告或清单被改动、来源记录不完整时保留旧目录并另存完整副本，不覆盖用户记录。

## 校验范围

校验官方 SHA256 和 ZIP 成员 CRC，限制压缩包 100 MiB、单成员 100 MiB、总展开 512 MiB、最多 20,000 个成员。超过上限明确失败，不截断下载后宣称成功。拒绝路径穿越、绝对路径、符号链接、设备、跨平台文件名冲突和加密/未知压缩成员。仅支持存储和 deflate ZIP。

静态检查读取 UTF-8 Markdown/HTML（每份最多 2 MiB）：Markdown 相对链接、HTML src/href，以及反引号内的 assets/、references/、scripts/ 字面路径。代码块示例、变量路径、外部路径进入人工核对线索。文件存在不证明外部模型、凭证、网络服务、系统工具等运行条件已经具备；纯正文里的隐含依赖也不保证被自动发现。

`qichelifestyle` 是已知缺件示例：发布包有11个文件，`references/fixed-models.md` 引用的4张 `assets/fixed-models/*.png`，以及 `SKILL.md` 引用的 `assets/shot-list-template.csv` 均不在官方 ZIP 中。应如实报告“发布包完整下载，引用资源缺失”。

## 失败与接续

请求单次超时30秒；同次下载的网络预算180秒，在请求、读取和重试之间检查剩余时间，并将可访问的套接字超时限制到剩余预算。系统 DNS 或底层调用的实际阻塞时间仍受运行环境影响，不承诺独立进程级硬超时。只读请求最多3次尝试，通常等待1、2秒。有效 Retry-After 完整遵守，超过本轮等待预算就保存 `retry_at` 并返回，下次联网前检查截止时间。TLS 证书失败、参数、HTTP 权限和宿主访问拒绝不重复重试；不得改变宿主沙箱以取得通过结果。

已完成的 ZIP 保留在 `.redskill-state/<identifier>/bundle.zip`；重复同一请求取得相同哈希时复用，再重新完成解压和发布。不承诺字节级断点续传：未完成的 ZIP 可以重新下载。用户看到 `task_busy` 时等待同一标识的另一个进程结束；锁随进程退出释放，残留锁文件不代表任务仍运行。

锁覆盖同一下载根目录内使用本实现的进程，不保护外部程序直接写入文件或跨设备并发。不要在下载时用其他程序修改 `.redskill-state`。状态损坏时先核对并保存现有材料，不直接删除整个下载目录。

所有正常输出为 JSON，失败退出2，成功（包括缺件交付）退出0。有限重试信息写到标准错误；日志含事件、原因、等待时间，不含签名 URL。结果自身可作为运行记录；没有常驻后台服务或无限增长日志。
